# Chessboard Printer

A simple C++ program that prints a chessboard pattern directly in the terminal.

---

## About

This program renders a standard 8×8 chessboard in the terminal using alternating light and dark squares. A clean and straightforward demonstration of terminal output and pattern logic in C++.

---

## Features

- Prints a chessboard pattern to the terminal
- Written in a single, lightweight C++ file
- No external dependencies

---

## Requirements

- A C++ compiler (g++ recommended, C++11 or later)

---

## Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/sthobvious/chessboard.git
   cd chessboard
   ```

2. **Compile the program**
   ```bash
   g++ -o chessboard chessboard.cpp
   ```

3. **Run the program**
   ```bash
   ./chessboard
   ```
